# Sound Assets

Place ambient sound files here for Focus Sessions:
- `rain.mp3` — Rain ambience (~500KB)
- `cafe.mp3` — Café chatter (~500KB)  
- `white-noise.mp3` — Ocean waves (~500KB)

These are played via the AmbientPicker in FocusSession. 
Without them, the picker works but no audio plays.

Recommended sources: freesound.org, pixabay.com (CC0 licensed)
